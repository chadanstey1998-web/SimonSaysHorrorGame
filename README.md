# Simon Says Horror Game — Android v1 Prototype

Package/application ID: `com.chadadventure.simonsaysthecave`
App name: **Simon Says Horror Game**
Target API: **36 (Android 16)**
Minimum API: 26
Version: 1.0.0 (versionCode 1)

## What is included
- Portrait horror survival game loop
- Creature continuously advances in real time
- Correct answers push the creature back
- Wrong answers/hesitation bring it closer
- Three lives, level, score, distance meter
- Six randomized brain-teaser types: Simon Says, odd-one-out, quick math, reverse sequence, word challenge, DON'T TAP trick
- Increasing speed/difficulty
- Game over + retry
- How-to-play screen
- Privacy policy link
- No ads, no analytics, no account system and no Android permissions in v1

## Build in Android Studio
1. Install the latest Android Studio and Android 16 / API 36 SDK.
2. Open this folder as a project.
3. Let Android Studio sync Gradle.
4. Run on your phone for testing.
5. For Google Play: **Build > Generate Signed App Bundle or APK > Android App Bundle**.
6. Create/use your permanent upload keystore and keep it backed up safely.
7. Upload the resulting `.aab` to the Closed testing track.

Important: Google Play requires new apps submitted after Aug 31, 2026 to target Android 16 / API 36 or higher.

## Before production
This is a functional first prototype. Test gameplay, difficulty, text scaling, sound, and device compatibility before production. Store screenshots should depict features that are actually included in the shipped build.
